# cementbopt

`cementbopt` contains the Bayesian optimization workflow developed for the high-throughput formulation of cement--salt hydrate composites for thermochemical energy storage.

The repository is intended as a companion code release for the associated scientific publication.

## Publication

Details of the methodology and results are described in:

**Alessio Mondello, Giulio Barletta, Luca Lavagna, Matteo Fasano, Matteo Pavese, Eliodoro Chiavazzo**, *High-Throughput Bayesian Optimization of Cement-Salt Hydrates Composites for Seasonal Thermochemical Energy Storage*, **arXiv** (**2026**)
